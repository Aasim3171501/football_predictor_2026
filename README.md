# Football Match Predictor ⚽

An end-to-end machine learning project that predicts football match outcomes using historical match data.

## Features

- Predict Home Win / Draw / Away Win
- Probability predictions
- Team form analysis
- Elo rating system
- Expected goals
- Interactive Streamlit dashboard

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-Learn
- XGBoost
- Streamlit
